# SCG-HMH, version 8 (erratum of v7): files in this deposit

Authors: Smart, Morgan Elliott; Smart, Jasper Keiron; Ara (Grok Bot AI collaborator). Ara is an AI system. Licence CC BY 4.0. New version of Zenodo record 10.5281/zenodo.23291052. Paper version v8; release package V10.

- `01_SCG_HMH_Closed_Derivative_Chain_v8.pdf`: the paper.
- `02_SCG_HMH_v8_Section_6.6_Cold_Side.pdf`: Section 6.6 (the Earth cold side) on its own.
- `03`–`09`: supplements (errata v7 to v8, key results, bench validation plan, open questions, reproducibility, transistor physics and data centres, further physics exploitations). Supplements 08 and 09 are new derivations, labelled as such.
- `10_SCG_HMH_Technology_Readiness_Benchmarks_v5.pdf`: companion of public benchmarks set against the v8 design values.
- `11_SCG_HMH_v8_reproducibility_scripts_and_outputs.zip`: the calculation script (needs Python and CoolProp), independent cross-checks, number checks, the section renderer, figures, and the expected outputs.

These are analytical results. Nothing has been demonstrated experimentally yet; the Phase-1 bench gate (σ > 5 S/m and > 50 W net) is the test.
